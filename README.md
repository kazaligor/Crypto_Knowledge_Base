# Криптовалюты: понятно о сложном

Адаптивный русскоязычный учебник-справочник о цифровых активах. Работает на iPhone, Android и компьютерах в современном браузере; после первого открытия PWA может работать офлайн.

## Что внутри

- 11 тематических глав: история, децентрализация, блокчейн, кошельки, виды активов, переводы USDT, TradFi vs crypto, CEX/DEX, риски, банковский продукт и российское регулирование.
- Адаптивная мобильная навигация, поиск по главам и словарь терминов.
- Раскрываемые ссылки на первичные и официальные источники.
- Без регистрации, серверной части, внешних библиотек, тестов, учёта прогресса и аналитики.

## Стек

Чистые HTML, CSS и JavaScript. PWA реализована через `manifest.webmanifest`, `sw.js` и `icon.svg`. Сборка и установка зависимостей не нужны.

## Локально

Откройте `index.html` в браузере. Учебник, навигация, поиск и словарь работают без сервера. Установка PWA и Service Worker требуют HTTPS или localhost.

## Публикация

Можно развернуть как статический сайт на GitHub Pages или Vercel. Для GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `/(root)`. После публикации откройте сайт в Safari и выберите «Поделиться» → «На экран Домой». На Android используйте меню браузера и пункт установки/добавления на главный экран.

## Обновление

Редактируйте `index.html` и коммитьте изменения в `main`. При обновлении кэша увеличивайте версию CACHE в `sw.js`.

## Важное

Ссылки ведут к официальным и первичным материалам. Законодательство, сети и условия эмитентов нужно перепроверять на дату применения. Это учебный обзор, а не юридическая или инвестиционная рекомендация.
