# Криптовалюты: понятно о сложном

Мобильный учебник-справочник о криптовалютах и цифровых активах. Приоритет — чтение и быстрый поиск информации, а не прохождение курса: нет тестов, баллов, обязательного порядка глав и отслеживания прогресса.

## Возможности

- 11 тематических глав: история, децентрализация, блокчейн, кошельки, типы активов, переводы USDT, TradFi и крипторынок, CEX/DEX, риски, банковские продукты и российское регулирование.
- Mobile-first интерфейс для iPhone, Android и настольных браузеров.
- Оглавление, поиск по главам и словарь терминов.
- PWA: установка на главный экран и offline-доступ после первого успешного открытия.
- Без аккаунтов, аналитики, внешних библиотек, backend и базы данных.

## Стек и структура

Проект использует только HTML, CSS и vanilla JavaScript. Никакой сборки или установки зависимостей нет.

- `web/index.html` — разметка и структура справочника.
- `web/styles.css` — стили и адаптивная вёрстка.
- `web/app.js` — навигация, поиск, словарь и регистрация Service Worker.
- `web/manifest.json` — параметры установки PWA.
- `web/sw.js` — кэширование для offline-доступа.
- `web/icon.svg` — иконка.

## Публикация

GitHub Actions автоматически публикует содержимое `web/` в GitHub Pages при каждом push в `main`. Рабочий процесс находится в `.github/workflows/pages.yml`. Vercel и другие внешние хостинги не используются.

Если публикация ещё не включена в настройках репозитория, выбери **Settings → Pages → Source: GitHub Actions**.

## Как открыть

- **iPhone:** открой опубликованный сайт в Safari → «Поделиться» → «На экран Домой».
- **Android:** открой в Chrome → меню → «Установить приложение» или «Добавить на главный экран».
- **Компьютер:** открой сайт в актуальном браузере.
- **Локально:** открой `web/index.html`. Основные материалы, поиск и словарь доступны и без сервера; установка PWA и Service Worker требуют HTTPS или localhost.

## Как вносить улучшения

Изменяй соответствующие файлы в `web/` и отправляй commit в `main`. GitHub Actions проверит наличие основных файлов и опубликует обновлённую версию. При изменении offline-ресурсов увеличивай идентификатор `CACHE` в `web/sw.js`, чтобы пользователи получили новую версию.
