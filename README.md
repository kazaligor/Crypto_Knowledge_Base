# Crypto Knowledge Base

Интерактивная автономная база знаний о криптовалютах. Основной файл: `crypto_knowledge_base.html`.

Для работы интерактивности откройте файл в полноценном браузере (Safari/Chrome), не во встроенном предпросмотре приложения «Файлы» или мессенджера. Для веб-версии включите GitHub Pages в настройках репозитория после добавления `index.html`.
